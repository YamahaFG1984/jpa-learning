基于 Manning《Java Persistence with Spring Data and Hibernate》

Java 持久化：JPA · Hibernate · Spring Data

这是对 Cătălin Tudose 所著 Java Persistence with Spring Data and Hibernate（618 页，20 章）及其配套源码的中文精读讲义。每一章都配有大量 SVG 图解，力求把「为什么这样设计」和「实际发出的 SQL 是什么」讲清楚。

20 章讲义 贯穿示例：CaveatEmptor 在线拍卖系统 源码：仓库根目录 Ch01/ – Ch20/ 环境：MySQL 8 / H2，Hibernate 5.6，Spring Data JPA 2.7，Java 17
建议的阅读路线

只想快速上手 → 第 2 章（三种方式的 Hello World）+ 第 4 章（Spring Data JPA 全貌）+ 第 10 章（EntityManager 与实体状态）。
要把映射写对 → 第 5–9 章连读，尤其第 8 章「要不要映射集合」的取舍。
要把性能调好 → 第 11 章（并发与锁）+ 第 12 章（n+1 与笛卡儿积）。这两章是排查线上问题的必修课。

Part 1 · 入门 ORM

CHAPTER 01
理解对象/关系持久化
五道范式失配裂缝：粒度、继承、标识、关联、导航。为什么需要 ORM。
CHAPTER 02
启动一个项目
同一个 Hello World 写三遍：JPA / 原生 Hibernate / Spring Data JPA，附性能对比。
CHAPTER 03
领域模型与元数据
CaveatEmptor 领域模型、透明持久化、POJO 关联脚手架、注解 vs XML、静态元模型。
CHAPTER 04
使用 Spring Data JPA
查询构建器机制、结果限制与分页、@Query、投影、修改型查询、Query by Example。

Part 2 · 映射策略

CHAPTER 05
映射持久化类
实体 vs 值类型、三种同一性、代理键与生成器策略、命名策略、@Subselect。
CHAPTER 06
映射值类型
基本属性、派生属性与列转换、可嵌入组件与嵌套、AttributeConverter 与 UserType。
CHAPTER 07
映射继承
四种继承映射策略的表结构、SQL 与取舍；混合策略、可嵌入类继承、多态关联。
CHAPTER 08
映射集合与实体关联
Set/Bag/List/Map 的主键差异、组件相等性、级联的四个台阶与孤儿移除陷阱。
CHAPTER 09
高级实体关联映射
一对一四种策略、一对多 bag/list/连接表、多对多的四种映射方式与三元关联。

Part 3 · 事务性数据处理

CHAPTER 10
管理数据
四种实体状态与转换图、持久化上下文三大职责、EntityManager 全部操作、游离态与 merge。
CHAPTER 11
事务与并发
四类隔离问题、ANSI 隔离级别、乐观锁与悲观锁、死锁规避、Spring 的 7 种事务传播。
CHAPTER 12
抓取计划、策略与剖面
代理与集合包装器、n+1 selects 与笛卡儿积、批量/子查询预抓取、join fetch、实体图。
CHAPTER 13
过滤数据
级联状态转换、JPA 回调与 Hibernate 拦截器、Envers 审计与版本化、动态数据过滤器。

Part 4 · 用 Spring 构建持久化应用

CHAPTER 14
把 JPA 与 Hibernate 集成进 Spring
依赖注入、DAO 模式的四种实现，以及如何把 DAO 泛型化。
CHAPTER 15
使用 Spring Data JDBC
不带 JPA「魔法」的持久化：查询方法、分页流式、关系建模的四种形态。
CHAPTER 16
使用 Spring Data REST
把 repository 导出为 REST 资源、ETag 条件请求、访问限制、REST 事件与投影。

Part 5 · 用 Spring 构建 NoSQL 持久化应用

CHAPTER 17
使用 Spring Data MongoDB
MongoDB 基础、MongoRepository 与查询方法、QBE、文档引用、MongoTemplate。
CHAPTER 18
使用 Hibernate OGM
用同一套 JPA API 操作 NoSQL：MongoDB 上手，然后切换到 Neo4j。

Part 6 · 查询与测试

CHAPTER 19
用 Querydsl 查询 JPA
类型安全的查询构建：过滤、排序、分组、连接、子查询、更新与删除。
CHAPTER 20
测试 Java 持久化应用
测试金字塔、Spring TestContext、配置文件（profiles）、测试执行监听器。

关于这份讲义

  • 内容依据仓库中的 jpa.pdf 逐章精读整理，代码路径与仓库中的 Ch01/–Ch20/ 源码目录一一对应。

  • 书中的重要论断、陷阱与作者的经验之谈用彩色提示框标出：note 背景 tip 建议 warn 注意 pit 陷阱。
  • 页面支持浅色/深色主题，跟随系统设置。
